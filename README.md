# Simulador-de-procesos
El tema “Simulador de procesos implementando Algoritmos de Planificación” consiste en el desarrollo de una herramienta que permita representar y analizar cómo un sistema operativo administra la ejecución de procesos mediante diferentes algoritmos de planificación. Un simulador de este tipo busca imitar el comportamiento de la CPU en los procesos.

Objetivo: Proporcionar un entorno interactivo donde el usuario pueda crear, visualizar y simular procesos de CPU, aplicando diferentes algoritmos clásicos de planificación, con un control visual de la cola de listos y el historial de ejecución.
